## 本轮改动与取舍

从最高分版本等价的清理版恢复基础，使用原根Docker、原编译器和编译参数，保持精确检索、主键等距排序、事务恢复及线程策略。

| 改动 | 目的与限制 |
|---|---|
| 已验证的常见execute请求直接提取SQL和ID | 减少JSON临时对象和重复扫描，复杂输入保留严格通用解析；原始NUL先拒绝，避免任何写入副作用 |
| 固定128维整数距离核 | 用独立部分和减轻累加依赖；只影响整数拒绝过滤，非128维和精确距离不变 |
| 并行两半共享K行见证的距离上界 | 减少部分无效候选；两侧堆和阈值缓存各自独立，共享只有原子上界，严格大于才拒绝 |
| 缓存无符号整数阈值 | 保留原浮点证书计算，避免每行将整数距离转double后比较；结构体保持88字节 |
| 限定落盘BIGINT过滤缓存 | 仅payload与向量索引都落盘时启用，最多两列、额外上限2MiB并计入现有预算；仍顺序扫描磁盘向量 |

没有纳入延迟精算TopK和两版短十进制解析。它们都完成了真实测试：部分数据看起来更快，但普通数据或父版本对照退步；原始正负结果与原型均留档，生产SQL解析恢复原实现。
