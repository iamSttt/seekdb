## 本轮候选

1. **请求预处理**：对已经完整验证的常见 ASCII execute 请求，直接保留 SQL、原始 ID 字节及 search mode，省去临时 JSON DOM 和 ID 重扫。嵌套、转义、非 ASCII、未知字段及不适用的操作回退到原严格 JSON 解析。必须保持全部输入验证先于执行、重复键错误、巨大 ID、UTF-8、shutdown 和事务语义。
2. **128 维整数距离**：在查询初始化时选择固定长度 SSE2/AVX2/AVX512 核，用独立部分和减小累加依赖；不改量化编码、浮点距离、拒绝证书、候选选择和非 128 维路径。128 个 int8 差值平方和最大为 8,323,200。仍有原来的每行函数指针调用，不能声称消除了 dispatch。

根 Docker 编译器、构建参数和线程策略保持不变，没有新增 PGO。两项均是尚待实测的假设，不预报官方分数。

## 验证与采用标准

先运行实际根镜像、公开 20 用例、交互协议、JSON/精确 TopK、恢复和 sanitizer 回归，再跑两项新增差分检查。固定长度测试另核对所有支持 ISA、独立整数 oracle、边界页、非 128 维和完整拒绝判断。请求测试用旧新镜像二进制逐字节比较 462 条输入，并检查后续数据库状态和重启。

性能初筛使用相同主机、EE 原始根构建、10k 行/128 维/1000 exact 查询；1 CPU 和 2 CPU 各六对，AB/BA 交错，2 GiB、swap=0，固定种子 7319。保留所有样本及重启、首查、内存和 I/O 数据，不按结果删除慢样本。首生命周期 wall/CPU 至少改善 5%、查询 wall/CPU 至少改善 10%，各主指标至少五对更快且两种顺序各自中位数改善，才继续完整保护和独立确认。
