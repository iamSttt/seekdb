## Method and correctness

Each comparison rebuilds the immutable baseline and candidate in the same CI
job and uses the official JSONL driver/session with 2 CPUs, 2 GiB RAM, read-only
root and writable `/data`. The workload has 10,000 float32 vectors of dimension
128, batches of 100 inserted rows, an explicit Flat index, and 1,000 requests per
mode (`exact` and `ann`), half filtered, with TopK 10. Mode order is interleaved.
Seeds are 7319, 19417 and 38021. Ratios below are medians of the three **paired
per-seed** exact-query time ratios, not ratios of pooled timings. Request latency
includes JSONL transport and response handling, but excludes workload generation
and validation. Index build is measured separately from query time.

CI checks include source tests, public organizer protocol fixtures, JSONL
regressions, exact-distance oracle tests and sanitizer checks. The sixth log
records 7,200 distance cases plus 63 midpoint cases, and 2,490 quantized pairs
with 3,686 safe rejections against independent integer/exact-distance oracles.
The synthetic benchmark compares ANN with exact results, checks selected queries
against a full-scan oracle, verifies primary-key ties, and checks all 10,000
record IDs plus ten vectors after restart. It is not an exhaustive oracle for
every benchmark query and does not include hidden organizer cases.

The changes preserve exact ranking:

- Float SIMD conservative bounds reject only candidates proven strictly beyond
  the exact heap boundary. Query-scoped constants and changing-threshold caches
  avoid repeated control-register checks and arithmetic.
- Resident scans and bounded equality postings reduce callback/filter work;
  winner projection reuse avoids redundant exact distance evaluation.
- Bounded norm-ordered traversal changes visit order while retaining full
  candidate coverage and primary-key tie handling.
- Resident int8 codes use a common power-of-two step `c`, nearest encoding and
  coordinate error at most `c/2`. For integer squared distance `Q`, triangle
  inequality gives real distance at least `c * (sqrt(Q) - sqrt(n))` when positive.
  An outward-rounded cap derived from `nextup(T)` proves when the canonical
  rounded-double distance is strictly above heap threshold `T`. Exact unsigned
  integer SIMD accumulation is bounded for dimensions up to 65,536. Codes never
  substitute for returned distances. Unsupported FP controls, query range,
  dimensions, coarse scales, missing memory budget or nonfinite bounds fall
  back to the existing exact path. AVX-512BW, AVX2 and SSE2 are dispatched only
  when supported; CI disable macros permit same-source comparisons.

## Resource and scoring limits

Sixth-run sampled cgroup memory peaks were 23,261,184–23,470,080 bytes for the
candidate, 23,658,496–23,736,320 for baseline, and 21,864,448–22,118,400 for the
previous candidate. Thus the additional codes increased memory versus the
previous version even though these samples remained below baseline. These are
cumulative per-container sampled `memory.peak` values, including accounted page
cache, not an official end-to-end peak across all process lifetimes.

The 10,000 by 128 int8 codes add 1,280,000 bytes (about 1.2 MiB) of index cache.
For sixth-run seed 7319, index construction rose from about 6.7 ms in `f87e8f0`
to 24.6 ms, and restart from 150.3 ms to 168.8 ms. Official query timing excludes
index preparation/startup, but B/M account for the whole lifecycle. A net benefit
for frequently rebuilt indexes or short query batches has not been established.

For example, candidate seed 7319 recorded device `8:0` with 0 read bytes and
6,070,272 write bytes before shutdown. Final shutdown/removal destroyed the
cgroup and later samples were null. The records do not guarantee final writeback
coverage; stacked-device counters must not be summed as physical I/O. Neither
these counters nor timing improvements establish official B/M or an overall E.

The published formula is `E=(Ewrite+2*Equery)/3`, each part weighting time 0.6,
bytes 0.2 and memory 0.2 after `f(R)=R/(1+R)`. It is bounded by 1, unlike the
platform's raw `2180.028190` display. No unsupported conversion between those
scales, QPS, rank or points is made here. The local synthetic default shape may
also differ from the hidden workload and deployment hardware.
